# Inbox — raw research drop zone

Dump anything here in any format: pasted reddit threads (.md/.txt),
links with a note about why, photos of failed prints, loose
observations. No structure required — naming like
`YYYY-MM-DD-topic.md` helps but isn't enforced.

This folder is **not** read during normal design work. Tell Claude to
"distill the inbox" and each item gets mined for durable rules, merged
into the right `references/` file with a [community] provenance tag,
and then cleared (with confirmation).

Good inbox material: specific numbers with context ("0.2 mm horizontal
expansion comp fixed my PETG holes on a K1"), failure modes with
diagnoses, technique writeups. Weak material: vibes, printer models far
from the K1 SE, aesthetics-only content.
